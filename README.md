# Python для Minecraft — статья

Однострочный статичный сайт-статья про написание скриптов на Python для Minecraft (библиотека `mcpi` + плагин RaspberryJuice).

## Структура

| Файл | Что внутри |
|------|------------|
| `main.html` | Сама статья. Разбита на тематические `<section>` (вступление, инструменты, установка, примеры кода и т.д.). |
| `styles.css` | Стили: светлая тема страницы, тёмная тема для блоков кода. |

Внешние зависимости подключаются по CDN:
- шрифт **Inter** (Google Fonts);
- **highlight.js** — подсветка синтаксиса в блоках `<pre><code>`.

## Как открыть

Просто открой `main.html` в браузере — сборка не нужна.

Для удобной разработки можно поднять локальный сервер, например:

```bash
python -m http.server 8000
```

и зайти на `http://localhost:8000/main.html`.

## Как править контент

- Текст и примеры кода — внутри соответствующей `<section>` в `main.html`.
- Каждая секция помечена HTML-комментарием, объясняющим её назначение.
- Внешний вид — в `styles.css` (секции тоже подписаны комментариями).
